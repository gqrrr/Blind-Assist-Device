# 视障人士辅助避障穿戴设备--Blind-Assist-Device

> **项目简介**:
  本项目旨在开发一款基于多模态融合与深度学习的视障人士智能避障穿戴设备，帮助视障人士更安全、更独立地出行。
  主要结合USB摄像头(YOLOv8 视觉识别)、超声波测距与STM32主控板，通过触觉（扁平震动马达）和听觉（语音播报）为视障人士提供双重避障反馈。

## 技术栈
  * 视觉端
  - 视觉识别：Python YOLOv8 OpenCV
  * 硬件端
  - 测距：超声波测距
  - 主控板：STM32
  - 避障反馈：触觉（扁平震动马达）和听觉（语音播报）
  *通信协议
  - 串口通信（UART）

## 研发日志与已知问题
  **2026.11.20 有关摄像头循环退出问题**
    1. 问题描述：在test_yolo.py中，无法关闭视频画面窗口。
    2. 原因分析：在‘results = model(frame,verbose=False)’中，忘记写verbose=False，导致程序延迟较大。
    3. 解决方案：将‘results = model(frame)’改为‘results = model(frame,verbose=False)’。


  **2026.11.20 有关视觉识别误差记录**
    1. 问题描述：YOLOv8在识别某些目标时存在误差：① 图像中的纸箱和A4纸被识别为laptop；② 图像中的水杯被识别为banana/remote/person。
    2. 原因分析：官方模型用于训练的数据集所包含的类别较少，无法准确识别图像中的纸箱、A4纸、水杯等目标，导致模型产生误判。
    3. 解决方案：后续计划通过收集特定场景图片，对模型进行微调，以提高识别准确率。
